# Upgrade oracle

This debug-only standalone instrumentation APK targets the installed `app.calisthenics.personal` app; it does not include app/domain implementation classes. It sets synthetic fixtures, reads them back through the installed target's actual store APIs, and verifies them after installing the new APK. It also tests a recoverable checkpoint and one-time legacy migrations in separate resets. `scripts/verify_upgrade.sh` requires this APK, the owner-selected baseline APK and the new APK; it checks their shared debug signing certificate and the baseline hash, records a synthetic workout on the old app, and compares preference and database snapshots.

Build using Gradle 9.3.1, Java 17, Android SDK platform 37 and the shared debug key, passing `-PdebugKeyPath=/absolute/path/to/shared-debug.keystore`. Inspect the APK's DEX to ensure application/domain/data and conflicting lifecycle implementations are not bundled; the instrumentation runner's transitive libraries can shadow target libraries. The script runs only with `ANDROID_SERIAL=emulator-*` and `KMP_TEST_EMULATOR_RESET=1`. The app data on that emulator is cleared; use a disposable `-read-only` emulator. Set `KMP_UPGRADE_EVIDENCE_DIR` to retain synthetic snapshot and instrumentation output. Supply adb, apksigner, Maestro and Python 3 on PATH.

This is a regression test, not an owner phone test. App APIs/fixtures and checkpoints must be validated against the original installed APK before interpreting the upgrade result. If the test cannot build, load, seed or decode, it fails rather than treating a fallback as preservation.

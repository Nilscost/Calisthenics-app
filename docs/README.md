## How the documentation is organised

- **Numbered documents:** plans and decisions from successive development stages. Their release and date provide context; earlier plans are historical records.
- **[Architecture decisions](adr/):** the rationale behind foundational technical choices.
- **[Evidence](evidence/):** verification logs, reviews and release checks. Results describe the revision tested, not a guarantee about every later revision.
- **[Media](media/):** images and demonstration review clips used in the documentation.
- **[Archive](archive/):** original specifications, early handoffs and superseded plans.
- **[Content review](review/):** exercise targets awaiting review.

Historical documents are retained to make the development process traceable. For the latest release state, use the status link above.

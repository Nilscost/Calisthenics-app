# R8.5 implementation and release evidence

The exercise-count control now starts a new automatic session selection, clearing
that objective's manual draft choices and per-break overrides while retaining the
latest global mode/preparation settings. Automatic selection retains the existing
one-logical-route rule, so pull-up/chin-up alternatives are not selected together.
Manual duplicate choices remain possible and survive navigation and unrelated
settings edits until the exercise count changes. Authored saved routines and
explicitly saved preferences are not rewritten.

Preview deletion now distinguishes an empty edited workout from an unrelated
planning error. Removing the only exercise leaves Add and Undo available and
keeps Start/Save disabled until usable work is restored. Removing the final row
of a longer list preserves the other row and persists across reopening. The
reported phone behavior has not been independently reproduced on a device;
these two cases are covered separately by automated UI regressions.

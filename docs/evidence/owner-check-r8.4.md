# R8.4 phone acceptance checklist

Candidate: 0.11.4-r8, versionCode 18. Automated verification is separate from this checklist. **No phone verification or owner acceptance is recorded.** Retain R8.3 for comparison; upgrade without clearing app data. Training content remains DRAFT.

Record phone/model, Android version, installed prior/new versions, music player and track source, speaker/Bluetooth route, app gain and system media volume. No connected device/emulator was available during implementation.

1. Upgrade the existing installation with saved routines, ordinary Preview edits, personal targets, audio preferences and an unfinished checkpoint intact. Recover the old workout; its remaining time, exact actual logs and old progression semantics must remain unchanged. A recovery prompt alone may timeout normally; a resumed or paused active workout stays awake while visible.
2. With an existing Rest Preview draft, return to Train, select Stretch and reopen Preview. All three controls agree; the timeline contains real compatible stretches. Repeat with an existing Flow draft, every set format, saved routine and editable fixed program. Where compatibility/repeat limits require passive rest, Preview explains it. Check Light, Dark and font size 1.3.
3. Change modes in both Preview forms, go back to Train and use direct Start. Compare with Preview Start: block order, stretches/rest, total duration, preparation time (e.g. 8 s), edited exercises, targets, cool-down and finisher must match. Switch modes repeatedly; dormant numeric rests and compatible picks return. A new global mode suppresses conflicting older break overrides; a later explicit break edit can customize it.
4. Open an ordinary workout: App levels is the default, including an upgraded installation. An unknown legacy ordinary draft may have its old rule reset once; other draft edits survive. Deliberate new rule edits persist within that objective. Saved Rep range/Custom and authored presets keep exact rules; switching away restores the ordinary default. Save/load/restart and backup/restore all configurations.
5. Start from tracked level 1. Explicitly log all required sets/sides at level-3 requirements: current level becomes 3 with success 1/3. Selecting 3, skipping, timer completion, or one exceptional set must not establish it. Two more qualifying sessions on distinct days within 14 days permit level 4. Check Progress and the next prescription. A compatible untried same-rung alternative should receive a conservative N−1 starting estimate, without transferred achievements or overwriting its own results. Automated distinct-day fixtures cover this timing; do not alter the phone clock to manufacture workouts.
6. Check an actual hold, unilateral exercise, weighted track, edited personal target and above-level-5 values. Exact actual numbers remain in History, there is no level 6, pain/manual easier/auto-off protections hold. Correct a result and replay/reopen Progress; no duplicated credit. Pre-edit earned history remains; incompatible pending credit does not satisfy raised targets.
7. Play downloaded music. At app gain 30% and then 100%, hear 3/2/1 warning beeps with voice ON and OFF, over speakers and Bluetooth. Include actual long rest, Stretch and Flow preparation. Check start/finish cues, gain 0 intentionally mutes both voice/beeps, silent demos, and unchanged system volume. Music must neither pause nor duck. If silent, capture `WorkoutAudio` logs (sample status, gain, playback result, available outputs); available outputs are not proof of the active route.
8. With a short system timeout, leave a long passive rest untouched beyond that timeout. Repeat Stretch, preparation, warm-up/cool-down, no-video blocks and manually paused unfinished session. Screen stays on only while the workout app is visible. Background the app: normal timeout remains permitted and workout timing continues.
9. Press the power button to lock. It must remain locked; timing and intended cues continue. Unlock back to the active workout: screen policy resumes. Pause/resume, recreate/recover, and check no stale countdown burst. Finish/cancel: normal timeout returns.
10. Export/restore a backup and repeat mode/rule/draft/personal-target checks. Saved routines are only changed on explicit Save. Old backups without a draft must not accidentally apply a stale local draft to restored settings.

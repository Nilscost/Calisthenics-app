## Phase 1 — domain KMP implementation, gates in progress

All domain logic now lives in `commonMain`, targeting JVM and Wasm/Node. Android consumes the JVM artifact. `java.time` becomes kotlinx-datetime 0.8.0 with caller-supplied zones and ISO Monday boundaries; Android converts dates at its existing locale-formatting boundaries. KotlinCrypto SHA2 0.8.0 replaces MessageDigest without changing the exact UTF-8 payload or lowercase padded hexadecimal checksum. JVM-only sorted-map and mutation helpers become common collection operations with sorted output preserved.

The 616 original test identities are recorded in `config/domain-test-baseline.txt`. All execute on both targets: 619 common tests pass (the originals plus checksum vectors, the committed seed checksum and Zurich seasonal/DST coverage), and one additional JVM fixture-file check gives 620 JVM tests. Neither target has failures or skips. `tools/check_kmp_test_parity.py`, included in host/CI verification, checks original identities, duplicates, skipped/failed tests and equality of common test sets. Fixture sources are generated from the four real repository inputs at build time; no copied catalog or seed snapshot can silently diverge.

Node is provisioned rather than downloaded by Kotlin so settings-level repository enforcement remains intact; CI pins Node 26.8.1. npm replaces Yarn. `@js-joda/timezone` 2.23.0 is pinned because datetime 0.8.0 uses core 3.2.0; newer timezone releases require core 5.7.0. The upstream compatibility issue is [kotlinx-datetime #627](https://github.com/Kotlin/kotlinx-datetime/issues/627). No force/legacy-peer-dependency override is used. The npm lockfile is committed. Browser execution remains a Phase 3 gate.

Local full verification (`JAVA_HOME` Java 17, shared debug signing key via the Gradle project property, `bash scripts/verify.sh`) exited 0: 620 JVM domain, 619 Wasm domain and 290 app tests, parity, lint, APK and content validation. The log is `docs/evidence/kmp-phase1-verify.log`. The APK certificate still matches the original digest recorded above; the Room migration SQL check also passes. Independent Terra review found no blocking source issue.

The signed install-over check passed with eight seeded sessions, all 16 database tables and six preference files identical (`docs/evidence/kmp-phase1-upgrade.log`).

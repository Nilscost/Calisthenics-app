## Answers (owner, 2026-10-13)
- **O1 ANSWERED: one Too easy jumps two levels.** Level 1 -> 3, 2 -> 4, 3 -> 5; level 4 or 5 -> level 1 of the next exercise in the chain. Accepting counts the skipped levels as done (stars, as with Edit in D5).
  Edge cases (assistant's choice, flag in the progress notes): no next exercise in the chain -> 4 -> 5, at 5 no card; kettlebell / weighted exercises: 4 -> 5, at 5 the existing heavier-weight card; under a Rep range rule (no levels) -> the next exercise. A Too hard or Pain in the same session cancels it, as today.
- **O2 ANSWERED (a):** planche lean shows "needs Plank" only while plank is below level 4. Owner had plank at level 5, so nothing to show; no code change, fix the check wording.
- **O3 ANSWERED (a) + clarification:** "Other types" still lists **every** type; the exercises of the same Progress tab come first and get a light accent box with "Same family: <tab>". Nothing is hidden.

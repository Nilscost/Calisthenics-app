# R8: breadth without a crowded training path

**Status: design review only. No content or behavior is approved by this note.** This review challenges [the progression discussion](27-progression-review.md) against the generated catalog and current app flows.

## Findings, highest impact first

1. **The new breadth can spill into default workouts.** The catalog has 533 entries, 517 outside the 16 routine-only Army drills. The visible Core, Pull, and Push trees alone contain 93, 51, and 47 exercises. Progress has a tab for each broad family group, and search returns up to 12 alphabetical matches. More significantly, default session sizing adds eligible fillers until it reaches 30 minutes, up to 12 exercises per round. The filler pool is profile- and prerequisite-filtered and selects one lowest-rank exercise per family, but the 379 additions still change what an ordinary workout can include. **Proposal:** keep a small, stable default set of movement families; make extra families an explicit “add more” choice. Do not let new catalog rows silently expand the familiar workout.

2. **The app has two different meanings of “next.”** Mastery uses each policy's explicit `mainSuccessorId`; the rep-range stepper instead sorts every usable member of a family by `difficultyRank`. A family rank is a useful browse hint, but it is not a reviewed path. In the current push-up family, the imported One-Arm Wall Push-Away is rank 12, between high incline/incline work and the knee push-up (rank 20); a range step can therefore surface it as the next choice even though the original incline policy points to Standard Push-Up. **Proposal:** make “next” follow the explicit main successor. Put alternatives and specializations in a separate chooser, clearly labeled as optional. If the stepper is intentionally a family browser, label it as such and stop calling it a progression stepper.

3. **Appending every source rung as a visible progression edge still creates clutter.** The importer preserves legacy edges and adds all contract `insertAfter` edges; the review report flags 47 parent rows for judgment, including 19 lower-rank insertion candidates. A tree that draws every edge treats support drills, alternate techniques, and candidates for the main line with equal visual weight. Only the feet-elevated/diamond pair is currently an owner-confirmed comparable group. **Proposal:** give each family one reviewed primary ladder. Show alternate paths below it as “other ways to train this movement,” and show prep/support work as recommendations rather than required rungs. Keep `routineOnly` hidden from browsing and general auto-fill, as it is now; fixed programs can still name their drills.

4. **Equipment and partial-range steps are poor universal gates.** An elevated pistol or a wall/box-assisted push-up may be a useful route for some people, but access to that prop is not evidence of readiness and lack of it should not block a bodyweight route. The planner filters an active exercise by profile, then can fall back to the routine's preferred variation if the active step is unavailable; that fallback is not the same as continuing through an explicit alternative route. Likewise, a partial pull-up or half one-arm push-up can support training without being a prerequisite to full-range strength. The current importer turns `insertAfter` and `alsoRequires` into conjunctive tier-5 app gates. **Proposal:** keep equipment-specific and partial-ROM work optional unless a source explicitly establishes it as a necessary step. For any proposed gate, state whether it means “all routes require this” or “this route requires this”; do not infer that from rank or adjacency.

5. **Programs are a good curated front door, but their list is dense.** The eight fixed programs preserve exact order and targets, and an unsupported equipment profile disables Start with the missing item named; they do not borrow level ladders or substitutions. The screen also expands every prescribed item and a flow switch in all eight cards. Pilates Intermediate alone has 23 items. **Proposal:** keep all eight programs, but make the list a compact title, duration, and equipment summary; open one program to see its exact sequence and flow setting. Keep each program's authored flow default and make overrides discoverable in its detail view.

## Choices to settle before changing routes

- Should the rep-range stepper mean “next main step” (recommended for coherence with mastery), or remain a difficulty-sorted family browser with a different label?
- Which small set of families is eligible for automatic time-filling, and should any newly added family enter that set without a separate review?
- For each apparent intermediate, is it a main-line prerequisite, an alternate route, or optional supporting work? Decide this explicitly for partial pull-ups, elevated pistols, half-range one-arm push-ups, and other equipment- or range-specific variants.
- Should visible progression trees emphasize one primary path and reveal optional branches on demand, while search remains the comprehensive library?

The useful product split is: **a complete library to browse, a small number of explicit main paths to master, and optional variations/support work that never become mandatory merely because they have a lower rank or an `insertAfter` link.**
